This is a description of supporting datasets for the paper titled, "Buried Glaciers and Ice Content of Mantling Materials in Deuteronilus Mensae, Mars," Baker and Carter, 2023, Journal of Geophysical Research: Planets. Data Set S1 (ds01.txt) is a text file table of SHARAD radargrams analyzed in the paper. Data Sets S2 and S3 (ds02.zip and ds03.zip) are provided as ESRI shapefiles (.shp) and compressed as separate zip files. The shapefiles can be opened in most geographical information systems (GIS) software. Shapefiles consist of three individual files: main file (.shp), index file (.shx), and dBASE table (.dbf). Descriptions of each column or attribute in the text file or shapefile is provided in the readme documentation.Data Set S1: ds01.txtList of all radargrams analyzed.SHARAD_ID =  SHARAD US Team RDR Product ID of the radarType = Indicates nighttime (Night) or daytime (Day) observationREFLECTOR = Indicates whether an Upper Plains reflector was observed (Y = yes, N = no).Data Set S2: ds02.zipZip file containing a point shapefile of all mapped reflectors with the Upper Plains mantle unit. Latitude and longitudes are from PDS SHARAD geometry files. Coordinates and measurements for each trace are after auto-extraction of maximum power values. Descriptions of each field in the shapefile are as follows:LATITUDE = latitude (degrees)LONGITUDE = longitude (degrees)SURF_X = x-coordinate of surface reflector trace in radargram (US Team RDR TIFF)SURF_Y = y-coordinate of surface reflector trace in radargram (US Team RDR TIFF)SURF_P = Power of surface reflector in radargram (units)SUBSURF_X = x-coordinate of subsurface reflector trace in radargram (US Team RDR TIFF)SUBSURF_Y = y-coordinate of subsurface reflector trace in radargram (US Team RDR TIFF)SUBSURF_P = Power of subsurface reflector in radargram (units)ELEV = MOLA surface gridded elevation (in meters)NUM = subsurface reflector trace number (some traces are broken up into several segments)ROOT = SHARAD Product ID (US Team RDR TIFF)DIFF_PIX = Difference in pixels between surface reflector and subsurface reflectordB_SURF_P = Power of surface reflector in radargram (in dB)dB_SUBSURF_P = Power of subsurface reflector in radargram (in dB)dB_DIFF = Difference in power between surface and subsurface reflectionsTIME_DEL = Two-way time delay of subsurface reflector (ms)DEPTH_5p75 = Depth to the reflector assuming a dielectric constant of 5.75SITE_ID = Site Name referenced in manuscript (A = Site A, B = Site B, C = Site C, D = Site D, N = other site location)Data Set S3: ds03.zipZip file containing a point shapefile of all mapped basal reflectors for LDA. Latitude and longitudes are from PDS SHARAD geometry files. Coordinates and measurements for each trace are after auto-extraction of maximum power values. Descriptions of each field in the shapefile are the same as the UpperPlains_Reflectors, with the additional fields:LOSS_dB_us = Power loss per microsecond (from time delay) of subsurface reflectorLOSS_dB_m = Power loss per meter (from depth measurement) of subsurface reflectorTHK_3p15 = Depth to the reflector assuming a dielectric constant of 3.15 (meters)Elev_SUBSF = Elevation of the subsurface reflector (meters relative to MOLA datum)
